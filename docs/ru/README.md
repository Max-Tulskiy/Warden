# Документация Warden

Канонический язык документации — русский; переводы лежат в
[../en/](../en/README.md).

* [architecture.md](architecture.md) — архитектура: модель активного агента,
  модель данных сервера, детектор изменений конфигурации, аутентификация,
  коллекторы агента, границы, ответы на типовые вопросы.
* [usage.md](usage.md) — развёртывание сервера через docker-compose,
  регистрация и установка агента (MSI/deb/rpm/pip), проверка без реального
  оборудования, честный статус живой проверки платформенного кода.

Назначение проекта, обязательные принципы разработки и принятые технические
решения — в [конституции проекта](../../.specify/memory/constitution.md),
которая имеет приоритет над остальной документацией.
